# 蒲田＋热海慢游：10天9晚草案

日期、航班与酒店仍待定。住宿沿用6＋3晚：第一基地由横滨改蒲田，第二基地热海。蒲田有4个完整主题日＋1个完整机动日，抵达与转场不算完整游玩日。横滨只保留山手日归；东京银座取消，户越银座仍作机动候选。

| 总日序 | 基地 | 默认安排 |
| --- | --- | --- |
| D1 | 蒲田第1晚 | 羽田抵达、入住、附近吃饭休息 |
| D2 | 蒲田第2晚 | 主题A：自由之丘→代官山→中目黑 |
| D3 | 蒲田第3晚 | 主题B：长谷／由比滨→稻村崎→七里滨 |
| D4 | 蒲田第4晚 | 主题C：吉祥寺→下北泽 |
| D5 | 蒲田第5晚 | 主题D：美国山→山手→港见丘→元町 |
| D6 | 蒲田第6晚 | 机动：蒲田休息，或户越银座半日 |
| D7 | 热海第1晚 | 蒲田→川崎换东海道线→热海，放行李休息 |
| D8 | 热海第2晚 | 热海坡地街景／海滨，或伊东Orange Beach半日 |
| D9 | 热海第3晚 | 未决定：富士市／下田／热海休息三选一 |
| D10 | 返程 | 热海→横滨换京急→羽田，按航班倒推 |

四主题日不锁死日期：晴朗能见度最好优先镰仓，其次横滨山手；阴天自由之丘、小雨吉祥寺与下北泽；大雨留蒲田休息。机动日可前移。每天一个主题，不把江之岛、寺社、横滨港口串点、人形町日本桥追加成任务。住宅区只走公开街道。

本攻略通勤默认JR／东急蒲田站，不是京急蒲田。两站约800米、步行约10分钟，酒店若在京急侧需加到JR／东急的时间。[大田区站区说明](https://www.city.ota.tokyo.jp/kuho/kuho_web/20160701/tokusyu.html)。机场日按实际航站楼与酒店导航，抵达晚不默认铁路仍运行、凌晨到达不默认提前入住。

自由之丘至代官山乘东横线各站停车；代官山步行下中目黑，走累可缩短。镰仓使用JR蒲田→横滨换横须贺线→镰仓，江之电共四段连长谷、稻村崎与七里滨；不要沿海岸公路长距离硬走。七里滨按实际日落提前到达，16:00–18:00仅为节奏参考。吉祥寺可经神田换中央线快速，避免不停本站的中央特快；下北泽返程经涩谷、品川，换乘步行另留时间。

山手从元町中华街站6号出口上美国山高台，再走山手、港见丘，之后下坡元町吃饭。洋馆外观随兴，不挨栋参观。[美国山官方交通](https://www.seibu-la.co.jp/mt_america/access.html)。

富士市是热海新增的晴天选项：东海道本线普通车热海→富士站（依班次直达或沼津换乘，约1小时），富士站北口→富士本町商店街／本町通→午饭咖啡→回站。富士站不是新富士站；不加吉原、梦之大桥或登山。富士山是否可见取决天气，先看[官方实时镜头](https://www2.city.fuji.shizuoka.jp/livecamera/index.htm)，[富士市商店街资料](https://www.city.fuji.shizuoka.jp/1005330000/miryoku/p008181.html)，[JR东海时刻查询](https://railway.jr-central.co.jp/time-schedule/search/)。D9三方案互斥，预算默认不收跨城票；选富士市才计其规划占位。

热海保留站旁酒店、海滨坡道、伊东半日与下田选项。轻装可走坡路；拖箱日先放行李，公交按当日站牌。箱根本次取消。返程早班须调整前一晚到蒲田／机场附近，并重核夜数与酒店。

预算保留两人、一间房和可编辑费用。共同预算输入迁移，原横滨／银座／逗子活动费用停用，新蒲田交通重新设规划占位；换主题日期不会重复计车费。日期与酒店未定，预算不是实际报价。路线细节、回程与购票方式见网页展开卡和[itinerary.json](itinerary.json)。
