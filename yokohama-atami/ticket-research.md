# 蒲田＋热海票务与交通说明

蒲田段与富士市线路说明更新于2026-10-04；既有热海票价沿用2026-09-28资料，实际出发前须再核。日期未定，不沿用引用方案中的2024票价或把43分钟／770日元当固定富士车次。全部预算可编辑。

| 区段 | 路线与购票 | 费用性质 |
| --- | --- | --- |
| 羽田→蒲田 | 京急空港线到京急蒲田，按实际酒店决定是否步行去JR／东急蒲田侧 | 预算300円／人，仅规划占位 |
| 主题A | 东急蒲田多摩川线→多摩川换东横线→自由之丘→代官山（各停）→步行中目黑→多摩川换蒲田 | 预算750円／人，仅规划占位；当日比较普通票与东急一日券，不默认一日券更省 |
| 主题B | JR蒲田→横滨换横须贺线→镰仓，江之电镰仓→长谷→稻村崎→七里滨→镰仓，再JR返蒲田 | 预算2200円／人，仅规划占位；JR同一张全程票不重复加横滨接驳，江之电四段 |
| 主题C | JR蒲田→神田换中央线快速→吉祥寺；京王井之头线→下北泽→涩谷，JR山手线内回り→品川换京滨东北线→蒲田 | 预算1400円／人，仅规划占位；JR／京王换运营方须换闸 |
| 主题D | JR蒲田→横滨，港未来线→元町中华街，返程反向 | 预算1050円／人，仅规划占位；东急券不覆盖港未来线 |
| 机动户越银座 | 东急池上线蒲田↔户越银座 | 预算500円／人，仅勾选时计入 |
| 蒲田→热海 | JR蒲田→川崎换东海道线普通车，热海行直达或小田原续换 | 预算2300円／人，仅规划占位 |
| 热海↔伊东普通车 | 旧核查纸票单程350円、往返700円 | D8选伊东才计费；出发前再核 |
| 热海↔下田普通车 | 旧核查纸票单程2210円、往返4420円；伊东可直通或换乘 | D9选下田才计费；特急费用另付，出发前再核 |
| 热海↔富士站 | 东海道普通列车，约1小时，直达或沼津换乘依日期班次；不是新富士站 | 预算1800円／人往返，仅规划占位；热海站进、富士站出可用普通票或互通交通IC（如Suica），按官方规则使用 |
| 热海→羽田 | 东海道普通车→横滨换京急，实际航站楼重查 | 预算1780円／人，仅规划占位，另留进站候车换乘及机场手续时间 |

D9默认未定，富士市、下田与休息互斥；D8伊东与热海休息互斥。步行与公共交通分别用Google Maps对应模式。建议时间是旅行节奏，不是确认班次。
