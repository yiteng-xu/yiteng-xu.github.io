# 九州海港慢游：修订后的9天8晚旅行计划

核查日期：2026-09-27。出发日期、航班和酒店尚未确定；以下为可调整方案。上海往返福冈，长崎3晚、小仓4晚、博多1晚。建议出发时间和耗时是规划估算，不是已确认的班次。

网页入口：https://yiteng-xu.github.io/kyushu/

## 第1天：入境九州，沿铁道去长崎

首日只安排交通、入住与港边散步。假设白天抵达福冈；晚到时把长崎移到次日，不赶末班。

住宿：长崎站周边 · 第 1 晚

### 按实际航班 · 国际楼 → 国内楼 → 博多

国际航站楼没有直通地铁；先入境、取行李，再乘免费航站楼接驳。建议入境后预留 60–90 分钟到达博多站，不包含航班延误。

- 机场免费航站楼接驳巴士｜国内线航站楼方向｜福岡空港国際線ターミナル → 福岡空港国内線ターミナル。换乘：国内线下车后按地下铁标识到 B2；预计：车程约 10–15 分钟，另加等车；建议出发：完成入境后。 提醒：接驳受道路交通影响，国际线没有楼内地铁入口。
- 福冈市地下铁 · 空港线｜姪浜 / 唐津方向｜福岡空港駅 → 博多駅。换乘：无换乘；预计：乘车约 5–6 分钟；建议出发：到达国内线后。 提醒：不要坐错七隈线；博多下车后跟随 JR 标识。

### 建议 12:00–14:00 · 博多 → 武雄温泉 → 长崎

先吃午饭再搭长途列车。两段列车在武雄温泉衔接，不是从博多一车直达的“西九州新干线”。

- JR 特急 Relay Kamome（リレーかもめ）｜武雄温泉方向｜博多駅 → 武雄温泉駅。换乘：武雄温泉换乘 Kamome；预计：约 60–75 分钟；建议出发：按航班与 JR 班次。 提醒：买联程票并确认两段座位；站台由车次决定，不固定写死。
- 西九州新干线 Kamome（かもめ）｜长崎方向｜武雄温泉駅 → 長崎駅。换乘：武雄温泉通常同站台对面换乘，听从现场指引；预计：约 25–35 分钟；建议出发：衔接前段列车。 提醒：博多到长崎合计通常约 1.5–2 小时，另留购票、候车时间。

### 入住后 / 17:00 左右 · 卸下行李，看看港口

只在体力允许时去海边散步；首日不塞博物馆或山顶夜景。

- 步行｜前往目的地｜長崎駅 → 長崎水辺の森公園。换乘：无换乘；预计：约 25–35 分钟；建议出发：建议 17:00。 提醒：不想走可在长崎站前乘 1 号崇福寺方向至出岛，再步行到港边。
- 步行｜前往目的地｜長崎水辺の森公園 → 長崎駅。换乘：无换乘；预计：约 25–35 分钟；建议出发：晚饭后。

餐饮：晚饭选长崎什锦面 champon、皿乌冬；抵达后在车站附近解决，不追热门排队店。

雨天或关闭替代：雨天取消港边散步，直接入住休息。若航班晚到，住博多并重新调整后续住宿。

## 第2天：坡道与港口旧时光

大波止港边 → 南山手街巷 → 港边 → 眼镜桥；全程公共街区散步，不安排任何博物馆或寺庙。

住宿：长崎站周边 · 第 2 晚

### 09:00 · 大波止与出岛 Wharf 海滨

先看长崎港与停泊船只，再到出岛 Wharf 公共海滨步道；它与收费复原展陈区域是不同地点。

- 步行｜前往目的地｜長崎駅 → 長崎駅前電停。换乘：无换乘；预计：约 5–10 分钟；建议出发：建议 08:45。 提醒：JR 站与电车站不是同一个入口。
- 长崎电车 · 1 号系统｜崇福寺行｜長崎駅前電停 → 大波止電停。换乘：无换乘；预计：约 6–10 分钟；建议出发：建议 09:00。
- 步行｜前往目的地｜大波止電停 → 長崎港ターミナル。换乘：无换乘；预计：约 3–5 分钟；建议出发：下车后。
- 步行｜前往目的地｜長崎港ターミナル → 出島ワーフ。换乘：无换乘；预计：约 3–5 分钟；建议出发：港边散步后。

### 11:30 · 新地午饭 → 南山手街景

在南山手、东山手公共街巷看洋楼与山城风景，不进教堂、不安排庭园。控制坡道步行，累了即折返。

- 步行｜前往目的地｜出島ワーフ → 新地中華街。换乘：无换乘；预计：约 10–15 分钟；建议出发：建议 11:30。
- 长崎电车 · 5 号系统｜石橋行｜新地中華街電停 → 大浦天主堂電停。换乘：无换乘；预计：约 6–10 分钟；建议出发：建议 13:00。 提醒：站名虽叫大浦天主堂，本计划只在街区公共道路散步，不进入教堂。
- 步行｜前往目的地｜大浦天主堂電停 → 南山手町 長崎。换乘：无换乘；预计：约 10–20 分钟；建议出发：下车后。 提醒：坡道较多；导航终点为街区而不是收费庭园。

### 15:00 · 港口散步 → 眼镜桥

从南山手下坡到海边休息，随后看中岛川与眼镜桥；不使用已经停运的 4 号电车。

- 步行｜前往目的地｜南山手町 長崎 → 長崎水辺の森公園。换乘：无换乘；预计：约 15–20 分钟；建议出发：建议 15:00。
- 步行｜前往目的地｜長崎水辺の森公園 → 新地中華街電停。换乘：无换乘；预计：约 10–15 分钟；建议出发：建议 16:00。
- 长崎电车 · 5 号系统｜蛍茶屋行｜新地中華街電停 → めがね橋電停。换乘：无换乘；预计：约 8–12 分钟；建议出发：建议 16:15。
- 步行｜前往目的地｜めがね橋電停 → 長崎眼鏡橋。换乘：无换乘；预计：约 3–5 分钟；建议出发：下车后。

### 晚饭后 · 回到长崎站

在中岛川附近吃晚饭，再按两段电车回站前；也可步行约 20–25 分钟回车站。

- 长崎电车 · 5 号系统｜蛍茶屋行｜めがね橋電停 → 市役所電停。换乘：市役所换乘 3 号；预计：约 2–5 分钟；建议出发：建议 19:00。
- 长崎电车 · 3 号系统｜赤迫行｜市役所電停 → 長崎駅前電停。换乘：市役所换乘；预计：约 5–8 分钟；建议出发：衔接前段。 提醒：符合官方线路组合的 IC / 非接触卡换乘优惠需按规定；现金不适用。
- 步行｜前往目的地｜長崎駅前電停 → 長崎駅。换乘：无换乘；预计：约 5–10 分钟；建议出发：下车后。

餐饮：午饭在新地中华街周边找什锦面或皿乌冬，晚上可尝土耳其饭。商圈只作为吃饭节点。

雨天或关闭替代：缩短海边和坡道步行，去车站餐饮区或有遮棚街道附近找咖啡休息；不添加展馆、寺庙或购物参观。

## 第3天：和平公园，稻佐山的蓝调时刻

上午走和平公园与浦上生活街道；下午休息，天气好再上稻佐山。

住宿：长崎站周边 · 第 3 晚

和平公园与爆心地公园均为公共开放空间，建议散步约 1–1.5 小时；不进入原爆资料馆或其他展馆。

- 长崎电车 · 1 或 3 号系统｜赤迫行｜長崎駅前電停 → 平和公園電停。换乘：无换乘；预计：约 15–20 分钟；建议出发：建议 09:00。
- 步行｜前往目的地｜平和公園電停 → 長崎平和公園。换乘：无换乘；预计：约 5–10 分钟；建议出发：下车后。
- 步行｜前往目的地｜長崎平和公園 → 原爆落下中心地碑 長崎。换乘：无换乘；预计：约 5–10 分钟；建议出发：建议 10:00。
- 步行｜前往目的地｜原爆落下中心地碑 長崎 → 平和公園電停。换乘：无换乘；预计：约 5–10 分钟；建议出发：散步后。

### 11:30–13:00 · 浦上生活街道与午饭

- 长崎电车 · 1 或 3 号系统｜1 号崇福寺行 / 3 号蛍茶屋行｜平和公園電停 → 浦上駅前電停。换乘：无换乘；预计：约 5–10 分钟；建议出发：建议 11:30。
- 长崎电车 · 1 或 3 号系统｜1 号崇福寺行 / 3 号蛍茶屋行｜浦上駅前電停 → 長崎駅前電停。换乘：无换乘；预计：约 5–10 分钟；建议出发：午饭后 / 建议 13:00。

### 日落前约 90 分钟 · 市区 → 稻佐山缆车

按当日日落倒推，不固定 17:00。索道与斜坡车是两套设备，分别查当日运航；本方案乘索道。可替代为官网预约免费接驳：需提前预约，不能随到随乘。

餐饮：浦上或车站周边午饭，晚饭在山下解决。带饮水和轻食，不把山顶餐厅作为唯一选项。

雨天或关闭替代：取消山顶和露天公园，在车站附近吃饭、找咖啡休息。夜景日可和晴天交换。

## 第4天：横穿北九州，住进小仓

上午移动，下午只沿紫川走一圈。长崎 → 武雄温泉 → 博多 → 小仓，三段列车写清楚。

住宿：小仓站周边 · 第 1 晚

提前购票。武雄温泉的衔接通常按成对车次安排；博多换车留约 20–30 分钟，带行李宁可宽松。

- 西九州新干线 Kamome｜武雄温泉方向｜長崎駅 → 武雄温泉駅。换乘：武雄温泉换 Relay Kamome；预计：约 25–35 分钟；建议出发：建议 09:00。

### 11:00–12:00 左右 · 博多 → 小仓

- 步行｜前往目的地｜小倉城 → 小倉駅。换乘：无换乘；预计：约 15–20 分钟；建议出发：晚饭后。

餐饮：午饭在博多或小仓站解决，晚上试小仓肉乌冬、烧鸟；旦过市场留到 D6 白天。

雨天或关闭替代：入住后休息，在小仓站附近找餐饮或咖啡，不安排室内展馆参观。

## 第5天：复古门司港，渡海吃唐户
